# Simplify gate

Host: `simplify.jobs`

Simplify is usually **not** the real application. Treat it as a redirect gate.

## Procedure

1. Navigate to packet URL on Simplify
2. Click **Apply**
3. If interstitial “Autofill with our extension” appears:
   - Prefer **I'll Apply Manually** (opens employer ATS)
   - Avoid Join/extension unless the user wants Simplify account flow
4. Detect new tab (`browser_tabs list`) → switch to ATS tab
5. Continue with the board playbook for that ATS (often Greenhouse)

## Notes

- Do not fill Simplify marketing/referral upsells as the application
- Keep Simplify tab; work in the ATS tab
