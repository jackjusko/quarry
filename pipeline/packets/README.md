# Packets

Each subdirectory is one staged application. Created by the **job-hunt** skill.

Naming: `YYYYMMDD-<short-company>-<short-role>` (slug, lowercase, hyphens).

See [`../config.md`](../config.md) for required files per packet.

Templates (tracked):

- [`_template/essay-answers.md`](_template/essay-answers.md) — after autofill when the form has essays; interview-prep reads this.
